# AI Countdown Studio

Zelfstandige Windows/Streamlit-app voor een verticale countdownvideo van exact
62 seconden: 1 seconde READY en daarna 60 tot en met 0.

## Mogelijkheden

- dezelfde vrouw of dezelfde man op alle wereldlocaties;
- wisselende vrouwen of wisselende mannen;
- gemengde, non-binaire en trans cast;
- Eiffeltoren, Vrijheidsbeeld, Taj Mahal, Big Ben, Sydney Opera House,
  Christus de Verlosser en het Colosseum;
- Kling Motion Control voor AI-videoclips;
- exacte lokale timer-overlay;
- eigen rechtenvrije of gelicentieerde housemuziek;
- MP4-download in 9:16.

## Windows starten

1. Download de repository als ZIP en pak hem uit.
2. Dubbelklik op start.bat.
3. Bij de eerste start wordt .env aangemaakt en in Kladblok geopend.
4. Vul je nieuwe KLING_API_KEY in, sla op en start start.bat opnieuw.

## Git Bash

    bash start.sh

## Veiligheid

Zet echte API-sleutels uitsluitend in het lokale bestand .env. Dit bestand is
uitgesloten via .gitignore en hoort nooit in GitHub.
